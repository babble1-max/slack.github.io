① Slack App を作成する
  1. api.slack.com/apps を開き「Create New App」→「From scratch」をクリック
  2. アプリ名（例: Daily Sender）とワークスペースを選択して作成
  3. 左メニュー「OAuth & Permissions」を開く
  4. 「Bot Token Scopes」に以下を追加:
    channels:read groups:read files:write chat:write chat:write.public
  5. 「Install to Workspace」をクリックしてインストール
  6. xoxb-... から始まる Bot Token をコピー
② 設定タブで設定する
  1. 「設定」タブを開き、Bot Token を入力して「接続」
  2. 送信先チャンネルを選択
  3. メッセージ・画像・送信時刻を設定
  4. 「設定を保存する」をクリック
  5. 「テスト送信」タブで動作確認
③ GitHub Actions を設定する（PC不要で毎日送信）
  1. GitHubリポジトリの「Settings」→「Secrets and variables」→「Actions」を開く
  2. 「New repository secret」をクリック
    名前: SLACK_TOKEN
    値: コピーした Bot Token を貼り付け
  3. リポジトリで slack_config.json と images/ フォルダをコミット・プッシュ
  4. 「Actions」タブを開き「Daily Slack Sender」を選択して「Enable workflow」
  5. 「Run workflow」でテスト実行できます
一度設定すれば、PCをオフにしていても毎日自動で送信されます ✅
送信時刻を変更する

.github/workflows/daily-send.yml の cron: を編集してください。
時刻は UTC（日本時間 − 9時間）で指定します。

日本時間cron 値
毎日 8:00"0 23 * * *" (前日UTC)
毎日 9:00"0 0 * * *"
毎日 12:00"0 3 * * *"
毎日 18:00"0 9 * * *"
毎日 21:00"0 12 * * *"
